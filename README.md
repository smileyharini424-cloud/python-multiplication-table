# Multiplication Table Generator

## Explanation

This program generates the multiplication table of a number.

## Problem Statement

Write a Python program that accepts a number and displays its multiplication table up to a specified limit.

## Features

* Accepts any integer
* Custom table range
* Uses loops
* Simple output format

## How It Works

1. Enter the number.
2. Enter the desired table limit.
3. Multiply the number by each value from 1 to the limit.
4. Display the table.

## Technologies Used

* Python
* Functions
* Loops
* User Input

## Data Structure Used

* No special data structure

## Methods Used

* `generate_table()`
* `main()`

## Sample Input

```text
Enter a number: 7
Enter table limit: 10
```

## Sample Output

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

## Time Complexity

O(n), where `n` is the table limit.

## Space Complexity

O(1)
